# Jatin Gulati Portfolio

GitHub Pages-ready executive portfolio.

## Files
- `index.html` — main website
- `.nojekyll` — prevents GitHub Pages/Jekyll processing issues
- `assets/profile.svg` — placeholder profile image

## To add real photo
Replace `assets/profile.svg` with a real image, or update the image path in `index.html`.

## Deploy
1. Upload these files to the root of your GitHub repository.
2. Go to **Settings → Pages**.
3. Select **main** branch and **root** folder.
4. Save.
