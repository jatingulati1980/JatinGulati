# Jatin Gulati — Full Advanced Portfolio

GitHub Pages-ready executive portfolio website.

## Includes
- `index.html`
- `assets/profile.svg`
- `.nojekyll`
- `README.md`

## Important
The site uses confidential wording: **Health Payer Client**.

## Add real photo
Replace `assets/profile.svg` with your real photo file, or change this line in `index.html`:

```html
<img src="assets/profile.svg" alt="Jatin Gulati profile photo">
```

to:

```html
<img src="assets/profile.jpg" alt="Jatin Gulati profile photo">
```

Then upload `assets/profile.jpg`.

## Deploy to GitHub Pages
1. Upload all files to the repo root.
2. Go to Settings → Pages.
3. Select Branch: `main` or your active branch.
4. Folder: `/root`.
5. Save.
